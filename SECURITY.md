# Security policy

Typseo has published `@typseo/*` packages at `0.1.0-beta.0`. We accept vulnerability reports for the current beta. Earlier beta versions may not receive a backport; maintainers will assess each report and publish a new version when a fix is ready.

Do not disclose a suspected vulnerability in a public issue. Use [private vulnerability reporting](https://github.com/typseo/typseo/security/advisories/new) to contact the maintainers. Include affected package versions, reproduction steps, and potential impact. Maintainers will coordinate disclosure with the reporter.

The [dependency security review](docs/dependency-security.md) tracks the current `braces` advisory and its exposure. Never commit API keys or credentials to this repository. See [CONTRIBUTING.md](CONTRIBUTING.md) for the local and CI checks.
