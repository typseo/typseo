# Security policy

Typseo is in early development and has no published SDK release yet. Supported versions will be listed here when packages are released.

Do not disclose a suspected vulnerability in a public issue. Use the repository's **Report a vulnerability** option to send a private report to the maintainers. Include affected versions, reproduction steps, and potential impact. Maintainers will acknowledge reports and coordinate disclosure after a fix is ready.

Never commit API keys or credentials to this repository. See [CONTRIBUTING.md](CONTRIBUTING.md) for the local and CI checks.
