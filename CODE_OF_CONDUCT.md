# Code of Conduct

We want Typseo discussions and contributions to be welcoming and constructive. Be respectful, assume good faith, and focus criticism on ideas and code rather than people. Harassment, threats, discrimination, and publication of another person's private information are not acceptable.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary. Report conduct concerns privately to the maintainer through their GitHub profile. Please include links and context, but do not post sensitive information in a public issue.
