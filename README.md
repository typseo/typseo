# Typseo

Typseo is an open-source, embeddable rich-text editor and SEO toolkit for React and Next.js projects. This repository is at **M0: Repository Foundation**. No editor, SEO scoring, AI, or external integration API is implemented yet.

## Requirements

- Node.js 20.9 or newer
- pnpm 10.4.1

## Local development

```sh
pnpm install
pnpm dev
```

Open <http://localhost:3000>. The playground currently verifies the Next.js workspace and does not simulate future product features.

## Checks

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm format:check
pnpm boundaries
pnpm security:tracked
```

The pre-commit hook also checks staged paths and content. Run `git config core.hooksPath .githooks` in a new clone to enable it. CI runs the tracked-file security check independently. `next-env.d.ts` is generated by Next.js and excluded from formatting.
