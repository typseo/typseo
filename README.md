# Typseo

Typseo is an open-source, embeddable rich-text editor and SEO toolkit for React and Next.js projects. `@typseo/core` provides editor-independent document analysis. `@typseo/react` and `@typseo/ui` provide the Tiptap v3 editor and optional UI; `@typseo/next` provides metadata helpers. M4 adds opt-in AI edit suggestions and human review. M5 adds optional server-only Ahrefs and Google Search Console adapters.

## Requirements

- Node.js 22.11+ (22.x), 24.x, or 26+
- pnpm 10.4.1

## Local development

```sh
pnpm install
pnpm dev
```

Open <http://localhost:3000>, or try the [public Playground](https://typseo-playground.vercel.app). It combines the Tiptap editor with live SEO analysis from `@typseo/core`. Drafts are saved to this browser's local storage; there is no account or backend. See the [playground guide](docs/playground.md) for controls, export, and limitations.

Visit the [Typseo homepage](https://typseo-docs.vercel.app/) and [public documentation](https://typseo-docs.vercel.app/docs), or run `pnpm dev:docs` locally at <http://localhost:3001>. Three standalone integrations live in [`examples/`](examples/README.md): Next.js App Router, Next.js Pages Router, and React/Vite. Each has its own run command and uses workspace packages. All seven libraries are also available as public betas under the [`@typseo` npm scope](https://www.npmjs.com/org/typseo); pin an exact beta version in applications.

## Checks

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm format:check
pnpm boundaries
pnpm security:tracked
pnpm security:history
```

The pre-commit hook also checks staged paths and content. Run `git config core.hooksPath .githooks` in a new clone to enable it. CI runs the tracked-file security check independently. `next-env.d.ts` is generated by Next.js and excluded from formatting.
