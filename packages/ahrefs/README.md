# @typseo/ahrefs

Optional server-only Ahrefs keyword adapter. Import from `@typseo/ahrefs/server` and supply credentials from your own server. See the [Ahrefs guide](https://typseo-docs.vercel.app/docs/integrations/ahrefs).

This package is available as a public beta on npm. Pin an exact beta version when installing; see [Installation](https://typseo-docs.vercel.app/docs/introduction/installation).
