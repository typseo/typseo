# @typseo/ai

Provider-agnostic edit contracts and an optional server-side AI adapter. See the [AI integration guide](https://typseo-docs.vercel.app/docs/ai-integration).

This package is available as a public beta on npm. Pin an exact beta version when installing; see [Installation](https://typseo-docs.vercel.app/docs/introduction/installation). No provider request occurs unless the host opts in.
