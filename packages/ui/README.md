# @typseo/ui

Optional, unstyled React editor and SEO components. See the [component guide](https://typseo-docs.vercel.app/docs/components) and [SEO toolkit](https://typseo-docs.vercel.app/docs/seo-toolkit).

`EditorToolbar` includes an accessible Paragraph/H1–H6 picker, basic inline marks, lists, and undo/redo. The host app supplies its own styles and persistence.

When the editor enables `textAlign: true`, the toolbar also offers Left, Center, Right, and Justify alignment.

This package is available as a public beta on npm. Pin an exact beta version when installing; see [Installation](https://typseo-docs.vercel.app/docs/introduction/installation).
