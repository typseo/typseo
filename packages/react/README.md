# @typseo/react

Headless Tiptap v3 bindings for React. See the [React hooks guide](https://typseo-docs.vercel.app/docs/editor/react-hooks).

Pass `textAlign: true` to `useTypseoEditor` or `createTypseoPreset` to enable paragraph and heading alignment. It is opt-in for compatibility with existing beta documents.

Pass `taskLists: true` to enable checkable, nestable task lists. Checked state is stored in Tiptap JSON; this extension is opt-in for compatibility with existing beta documents.

This package is available as a public beta on npm. Pin an exact beta version when installing; see [Installation](https://typseo-docs.vercel.app/docs/introduction/installation).
