The Inter Tight variable TTF was sourced from the
[`google/fonts` repository](https://github.com/google/fonts/tree/fac60545cc0de9d4eff6eb5b1ab88bcdfc9ecc69/ofl/intertight)
at commit `fac60545cc0de9d4eff6eb5b1ab88bcdfc9ecc69`.
The Regular (400) and Bold (700) static TTF files were generated from that
variable font with fonttools 4.60.1 for the Open Graph image renderer.
The website itself loads Inter Tight through Next.js `next/font/google`.
See `OFL.txt` for its license and copyright notice.
