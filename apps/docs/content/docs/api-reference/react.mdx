---
title: React API
description: useTypseoEditor and its actual options from @typseo/react.
---

`@typseo/react` exports `useTypseoEditor` and types `UseTypseoEditorOptions` and `TypseoEditorInstance`. The hook returns a Tiptap `Editor | null`.

```ts
interface UseTypseoEditorOptions {
  value?: string;
  defaultValue?: string;
  onChange?: (html: string, editor: Editor) => void;
  extensions?: AnyExtension[];
  starterKit?: boolean;
  editable?: boolean;
  editorProps?: EditorOptions['editorProps'];
}
```

Use either `value` or `defaultValue`. External controlled updates do not echo `onChange`. The instance is initially null until client initialization; `immediatelyRender` and transaction-driven React rerenders are disabled in the hook implementation.

Source: [`packages/react/src/use-typseo-editor.ts`](https://github.com/typseo/typseo/blob/main/packages/react/src/use-typseo-editor.ts).
