## The toolkit at a glance

| Layer             | Package                                       | Responsibility                                   |
| ----------------- | --------------------------------------------- | ------------------------------------------------ |
| Analysis          | `@typseo/core`                                | Pure, synchronous SEO rules over a page snapshot |
| Editing           | `@typseo/react`                               | Headless Tiptap v3 hook                          |
| Interface         | `@typseo/ui`                                  | Optional, unstyled editor and SEO components     |
| Publishing        | `@typseo/next`                                | App Router metadata and Article JSON-LD helpers  |
| Optional services | `@typseo/ai`, `@typseo/ahrefs`, `@typseo/gsc` | Server-side provider adapters                    |

Typseo does not provide hosted storage, accounts, publishing, or automatic ranking. Your app owns the content model and deployment. See the [architecture](/docs/introduction/architecture) before choosing packages.
