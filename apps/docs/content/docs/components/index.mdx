---
title: Components
description: Optional React components you can style and compose in your own application.
---

The components in `@typseo/ui` are intentionally unstyled. They expose accessible structure and behavior while your application supplies CSS. Editor exports live at the package root; SEO, metadata, and AI components use explicit subpaths.

| Import path                  | Components                                              |
| ---------------------------- | ------------------------------------------------------- |
| `@typseo/ui`                 | `TypseoEditor`, `EditorToolbar`                         |
| `@typseo/ui/seo`             | `SEOScore`, `SEOChecklist`, `SERPPreview`, `SEOSidebar` |
| `@typseo/ui/metadata-editor` | `MetadataEditor`, `KeywordInput`                        |
| `@typseo/ui/ai`              | `AICommandMenu`, `AIChatPanel`, `AIChangesPreview`      |

Try the [live preview](/docs/components/preview), inspect [props](/docs/components/props), or follow [usage examples](/docs/components/usage-examples).
