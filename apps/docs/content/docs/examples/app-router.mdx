```bash
pnpm --filter @typseo/example-app-router dev
```

Inspect [`examples/nextjs-app-router`](https://github.com/typseo/typseo/tree/main/examples/nextjs-app-router). It separates a client editor from server-owned metadata. The example illustrates how `@typseo/core`, `@typseo/ui`, and `@typseo/next` fit together without making the editor a metadata source at build time.

Adapt its state and styling to your application. Configure an actual site origin before deploying canonical metadata or JSON-LD; do not publish a placeholder domain.
