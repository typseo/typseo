title: Examples
description: Runnable workspace hosts for Next.js, React/Vite, and the Playground.
---

All examples run from the monorepo; Typseo packages are still private. They show how to own state, CSS, and page metadata in the host application.

| Example                                             | What it demonstrates                                                |
| --------------------------------------------------- | ------------------------------------------------------------------- |
| [Playground](/docs/examples/playground)             | Documents, editor, SEO analysis, local drafts, and optional AI demo |
| [Next.js App Router](/docs/examples/app-router)     | Client editor with server metadata and JSON-LD                      |
| [Next.js Pages Router](/docs/examples/pages-router) | Explicit `next/head` metadata, without the App Router helper        |
| [React/Vite](/docs/examples/react-vite)             | Framework-free editor and live SEO score                            |

Run `pnpm install --frozen-lockfile` at the repository root first.
