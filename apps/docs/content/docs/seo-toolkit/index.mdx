title: SEO Toolkit
description: Deterministic checks over an editor-independent page snapshot.
---

`@typseo/core` analyzes plain data. It does not inspect the DOM, fetch a page, or parse Tiptap HTML. `@typseo/ui/seo` renders the resulting analysis without recalculating it.

Start with [SEO Engine](/docs/seo-toolkit/seo-engine), then understand the [score](/docs/seo-toolkit/seo-score), [checklist](/docs/seo-toolkit/checklist), [metadata controls](/docs/seo-toolkit/metadata), and [SERP preview](/docs/seo-toolkit/serp-preview).

<Callout type="warning" title="Editorial heuristic">
  A score is not a ranking forecast. Character ranges and word-count thresholds
  are default editorial guidance and can be replaced with your own `SeoRule[]`.
</Callout>
