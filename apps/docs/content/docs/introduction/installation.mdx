## Prerequisites

- Node.js **22.11+ (22.x), 24.x, or 26+**. Changesets 3 requires this runtime for workspace tooling.
- pnpm **10.4.1**, as pinned by the root `packageManager` field.
- Git and a modern browser.

<Callout type="info" title="Public beta">
  All seven packages are published at `0.1.0-beta.0`. Pin the beta version while
  evaluating the API; it is not a stable release.
</Callout>

For an existing application, install only the packages it needs:

```bash
pnpm add @typseo/core@0.1.0-beta.0
```

Use `@typseo/react` for the Tiptap editor, `@typseo/ui` for optional components,
and `@typseo/next` for Next.js metadata helpers. The AI, Ahrefs, and GSC adapters
are optional and server-only where documented.

<Steps>
  <Step>
    ### Clone and install

    ```bash
    git clone https://github.com/typseo/typseo.git
    cd typseo
    pnpm install --frozen-lockfile
    ```

  </Step>
  <Step>
    ### Run an app

    ```bash
    pnpm dev
    pnpm dev:docs
    ```

    Playground opens at `http://localhost:3000`; docs open at `http://localhost:3001`.

  </Step>
  <Step>
    ### Check the workspace

    ```bash
    pnpm typecheck
    pnpm test
    pnpm build
    ```

  </Step>
</Steps>
