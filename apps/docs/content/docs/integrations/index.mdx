---
title: Integrations
description: Framework helpers and optional, server-only external data adapters.
---

Use [Next.js](/docs/integrations/nextjs) for App Router metadata, or [React/Vite](/docs/integrations/react-vite) for a framework-independent editor and SEO analysis. [Ahrefs](/docs/integrations/ahrefs) and [Google Search Console](/docs/integrations/google-search-console) are opt-in server adapters. They are not browser SDKs and are not wired into the Playground by default.

All seven packages are available as public betas on npm. Run the examples in this repository to evaluate integration without publishing an application.
