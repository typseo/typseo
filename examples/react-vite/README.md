# React + Vite example

Run `pnpm install` at the repository root, then `pnpm --filter @typseo/example-vite dev`. Open <http://localhost:3004>.

This example uses `@typseo/ui` and `@typseo/core` without Next.js. The host controls the title and description, while editor text is extracted with block separators for analysis. State is in memory; a static Vite HTML title is not a substitute for published page metadata.
