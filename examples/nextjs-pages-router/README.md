# Next.js Pages Router example

Run `pnpm install` at the repository root, then `pnpm --filter @typseo/example-pages-router dev`. Open <http://localhost:3003>.

The page renders its title and description using `next/head`; `@typseo/next` targets App Router and is intentionally absent. The interactive editor is loaded without SSR and feeds reader-visible text into the core analyzer. Edits are in memory only. Supply your own persistence and actual production metadata when integrating.
